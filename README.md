# GDPR-Compliant Contact Form
**Legal & Ethical Theme – University Assignment**

Live demo → (https://faizanali-2004.github.io/GDPR-contact-form--Example/)  

## Purpose
This is my submission for the **Legal and Ethical** theme.  
This contact form follows **UK GDPR / Data Protection Act 2018** rules.

## Features that prove I understand the law
- No cookies, no trackers, no third-party scripts
- Explicit, unbundled consent checkbox (required)
- Separate optional newsletter consent
- Data minimisation – only collects only name, email, message
- Transparent privacy notice on the page (Article 13 GDPR)
- Honeypot field to stop spam bots (no CAPTCHA needed)
- Red star (*) on required fields
- All CSS in separate file, clean & commented code

## Files
- `index.html` → main page
- `style.css` → all styling (no external files)

## How to run
Just open `index.html` in any browser or visit the live GitHub Pages link above.
